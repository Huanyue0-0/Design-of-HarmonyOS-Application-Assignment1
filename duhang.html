关于我

你好！我是杜杭，中国科学技术大学软件学院的硕士研究生，目前在合肥高新校区学习。我是一名喜欢「动手造东西」的程序员，从算法竞赛到独立开发小工具，一路走来最享受的，是把一个模糊的想法一步步变成能真正跑起来的软件。

我的兴趣集中在后端工程、数据存储与云原生方向，平时喜欢折腾服务器、写自动化脚本，也热衷于研究数据库和中间件的底层实现。除此之外，我也在持续学习前端，希望把技术栈打通，做一名更完整的工程师。

爱好与兴趣

写代码之外，我有几个让我放松又充实的爱好：

  • 跑步与骑行 - 喜欢沿着环巢湖绿道骑行，用运动清空大脑。
  • 电子游戏 - 偏爱策略类和独立游戏，也爱研究游戏背后的机制设计。
  • 自制咖啡 - 手冲是每天开工前的小仪式，喜欢研究不同豆子的风味。

职业技能发展规划

我的长期目标，是成为一名擅于解决复杂系统问题的后端工程师。围绕这个目标，我把成长拆成三个阶段：

  1. 第一阶段 - 夯实工程基本功（研一）：系统复习数据结构、操作系统与计算机网络，深入掌握 Go 与 Python，熟悉 Linux、Shell 与 Git 协作，并建立一个自己的技术博客沉淀学习笔记。
  2. 第二阶段 - 深入后端与数据（研二）：主攻分布式存储与中间件，学习 MySQL 调优、Redis、消息队列与服务治理，进入企业实习，参与真实的大规模后端项目并尝试开源贡献。
  3. 第三阶段 - 沉淀与精进：在云原生与数据工程方向形成自己的技术壁垒，能够独立设计与演进一套高可用后端系统，成为团队里值得信赖的技术骨干。

目标岗位：后端工程师 方向：云原生 + 数据 持续学习中
