关于我

你好！我是中国科学技术大学软件学院的硕士研究生郑金亮，目前主攻大数据处理与后端系统方向。我喜欢研究数据如何被高效地存储、流转与利用，也热衷于把复杂问题拆解成清晰可靠的工程方案。

职业发展目标与规划

我的长期目标是成长为一名资深后端 / 大数据工程师。为此我制定了如下分阶段计划：

  1. 第一阶段 - 打牢基础（研一）：吃透数据结构、算法与操作系统原理，熟练掌握 Python 与 Java，系统学习数据库与计算机网络，坚持在 LeetCode 上刷题保持手感。
  2. 第二阶段 - 工程实战（研二）：进入企业实习积累真实经验，掌握 Spring Boot、消息队列与分布式缓存的落地用法，关注性能优化与代码评审，并尝试参与开源项目。
  3. 第三阶段 - 方向深耕（研三）：在分布式系统或大数据平台方向持续深入，形成体系化的架构能力，成长为可以独当一面的工程师。

目标岗位：后端 / 大数据工程师 方向：分布式 · 云原生 坚持运动中
